# Dani Therapies

MVP do novo site multilíngue da Dani Therapies.

## Escopo

- Página principal institucional
- Páginas separadas para sessões, cursos e blog
- Rotas em português, inglês, espanhol e holandês
- Checkout preparado para Stripe
- Estrutura de conteúdo preparada para Supabase
- Formulários de contacto e inscrição
- SEO base com sitemap, robots, canonical e `hreflang`

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000/pt`.

## Validação

```bash
npm run lint
npm run build
```

## Segurança

Nenhuma chave real deve ser versionada. Use variáveis de ambiente apenas no
ambiente adequado e configure produção diretamente na plataforma de deploy.
